# Desafio 1 — Landing Page + DataLayer

## Arquivo principal
`index.html`

## Como testar
1. Abra `index.html` no navegador.
2. Pressione F12 e abra **Console**.
3. Digite `dataLayer` e pressione Enter.
4. Clique nos links e consulte `dataLayer` novamente.
5. Tente enviar o formulário vazio: não deve existir evento de submit.
6. Preencha todos os campos corretamente e envie: o evento deve aparecer.

## GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html` para a raiz.
3. Vá em **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione `main` e `/ (root)`.
6. Salve e aguarde a URL pública.
